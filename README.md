# SprintNotes

A minimal Server Actions demo built with Next.js, Tailwind, shadcn/ui, Better-SQLite, and server-rendered TypeScript.

## Getting Started

```bash
npm install
npm run dev
# open http://localhost:3000
```

## Scripts

- `npm run dev` start the development server
- `npm run build` run a production build
- `npm run lint` lint the codebase
